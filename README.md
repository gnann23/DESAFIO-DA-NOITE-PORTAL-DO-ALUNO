# DESAFIO-DA-NOITE-PORTAL-DO-ALUNO


. Contextualização
Uma instituição de ensino iniciou o desenvolvimento de um sistema denominado Portal do Aluno, cujo objetivo é permitir que estudantes realizem um cadastro simplificado e consultem suas informações durante a navegação.
Entretanto, o desenvolvedor responsável precisou interromper suas atividades antes de concluir o projeto.
Como consequência, o sistema foi entregue com diversos problemas:
Arquivos desorganizados e com nomes inadequados.
Funcionalidades parcialmente implementadas.
Trechos de código ausentes.
Falhas na comunicação entre as páginas.
Ausência de algumas validações.
Problemas no gerenciamento das sessões.
A instituição contratou sua equipe para recuperar o sistema e concluir o desenvolvimento.
Vocês receberão uma pasta contendo os arquivos PHP e um documento README com orientações sobre a organização e o funcionamento esperado.
